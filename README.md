# Flapverse

All memes. One place. Discover memes, GIFs and templates across public sources, search any topic and save favorites in your browser.

[X: @flapverse_fun](https://x.com/flapverse_fun)

Run locally: `python tools/serve.py`, then open the address printed by the server. This is a static site; no build step is needed.

Live sources include Lemmy, Reddit, Bluesky, Mastodon and Imgflip. Tenor, Giphy and Imgur use optional user-provided API keys in Settings. Your collection stays in browser storage.
